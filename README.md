# Primitive DB

## Управление таблицами

Запуск программы:

```bash
uv run database
```

Доступные команды:

```text
create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...
list_tables
drop_table <имя_таблицы>
help
exit
```

Поддерживаемые типы данных: `int`, `str`, `bool`.


## CRUD-операции

Данные каждой таблицы сохраняются в отдельном json-файле в директории `data/`.

```text
insert into <имя_таблицы> values (<значение1>, <значение2>, ...)
select from <имя_таблицы>
select from <имя_таблицы> where <столбец> = <значение>
update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>
delete from <имя_таблицы> where <столбец> = <значение>
info <имя_таблицы>
```

Строковые значения необходимо записывать в кавычках. Значение `ID` передавать при добавлении записи не нужно.
